# YouAnalyser: Provide Standardized Analytics Products for YouGov DACH

A collection of functions that serve as tools for YouGov DACH Analytics
Partners. The package currently provides functions for data processing
of labelled survey data, exploratory data analysis, Key Driver Analysis,
Van Westendorp Price Sensitivity Meter analysis, and Segmentation
(Cluster Analysis). Planned additions include Structural Equation
Modeling, Implicit Association Tests, and MaxDiff.
